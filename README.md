# ⚡ SmartEnergy – Energy Management Web App

A full-stack MERN application to track electricity usage, manage devices, analyze energy consumption, and monitor carbon emissions in real-time.

---

## 🚀 Live Demo
👉 https://engeryconsumption.netlify.app  

---

## 📌 Features

- ⚡ Calculate electricity consumption and cost
- 🔌 Add & manage electrical devices
- 📊 Interactive charts (Bar, Line, Pie) using Recharts
- 🌱 Carbon emission tracking
- 📈 Monthly usage analytics
- 🔐 JWT Authentication (Login/Register)
- 🌓 Dark/Light theme support
- 📱 Fully responsive UI

---

## 🛠️ Tech Stack

### Frontend
- React.js
- CSS (Custom Styling)
- Recharts
- React Router

### Backend
- Node.js
- Express.js
- MongoDB (Mongoose)
- JWT Authentication
- REST APIs

### Deployment
- Frontend: Netlify
- Backend: Render
- Database: MongoDB Atlas
